# Skills-Connect Spaza-App V1

Mobile-first tuckshop stock and sales tracker.

## Included
- Mixed-basket sales
- Loose, prepared and packaged products
- Product CRUD
- Optional barcode field
- Camera barcode scan using BarcodeDetector when supported, with manual barcode fallback
- Stock-in / prepared batch entry
- Physical stock count and reconciliation
- Low-stock alerts
- Daily sales and units summary
- Sales and stock movement history
- Local persistence via localStorage
- Installable PWA shell and offline cache

## Run locally
Serve this directory over HTTP, e.g. `python3 -m http.server 8080`.
